# Creative Agency Website

A modern and responsive frontend project inspired by immersive digital agency experiences.

This project was developed as part of a Frontend Developer Internship assessment and focuses on recreating the first two sections of the Wonder Makers Digital website with similar interactions, animations, and overall user experience.

## Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## Features

- Smooth animations and transitions
- Interactive UI elements
- Responsive design for multiple screen sizes
- Modern agency-style layout
- Clean component-based structure
- Optimized frontend experience

## Installation

Clone the repository:

```bash
git clone https://github.com/lakshmijahnavik/Wonder-Makers.git
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

## Project Objective

The objective of this project was to recreate the interactions and immersive frontend experience of a modern creative agency website while maintaining responsiveness and clean frontend architecture.
